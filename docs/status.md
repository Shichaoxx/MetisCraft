## 目标

做训练 Jev 类决策模型（System One）的工具包（2026-11-03 确定）：

- **内容**：模型一次前向给出结构化判断（是非、选择、打分、排序）和校准过的概率，与大模型的慢思考分工。
- **形式**：对标 verl、LlamaFactory，模型、训练算法、微调方式、数据、训练与推理后端都可以组合替换。

设计理念的方向是"训练有素的直觉"：把大模型的慢思考训练成又快、又知道自己有多准的判断。具体措辞待定。

项目名定为 **MetisCraft**（2026-11-03 确定）：包名、import、命令行统一为 `metiscraft`，PyPI、GitHub、Hugging Face 均无同名。希腊语 mētis 指工匠与航海者因时因地的实践智慧，兼有手艺与机巧两层；英语 craft 同样兼有这两层，是它的译名。原名 `metis` 在 PyPI 已被 METIS 图划分库的封装占用，AI 领域同名项目也多。

## 早期版本 Metis 0.1.0（已归档）

tag `metis-v0.1.0`，提交 `fac3a4d`。内容：Qwen3 Base + MLP ScoreHead 候选打分、NFCorpus 排序闭环、BoolQ 读出研究，以及未实现的 v2 升级方案。

重写原因：

1. **没有可替换的部件。** 模型只支持 Qwen3，任务靠 if/else 分支，只有打分用的监督损失，训练是单个 `train()` 函数，只能单卡。
2. **自己的实验绕开了工具包。** BoolQ 研究脚本各自写训练循环、LoRA 接入和保存格式，研究代码多于核心库。
3. **唯一的模型没训好，也缺对照。** NFCorpus test nDCG@10 为 0.291，低于原始 Qwen3-Reranker 的 0.355，且未报告 BM25 本身的分数；BoolQ 各组全部预测肯定；LoRA 学习率 2e-5 偏低。
4. **v2 方案仍在给这一个模型补功能**，做完也不是工具包。

数据契约、NFCorpus 准备与评测、张量图等可复用部分按需从 tag 取回，不整体继承。
